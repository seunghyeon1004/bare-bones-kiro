1. **apps/which-bin/** table.json, copy.json, theme.css. Outcomes: paper, cartons, glass bottles, cans, clear PET bottles, plastics, plastic film, styrofoam, battery box, lamp box, general waste bag (종량제봉투, explain it in English), special sack for non-combustibles (특수규격마대), ask your district office. Write every rule from the quote table in docs/sources/README.md, with `source.at` set to that row's Ref and the instruction (rinse, peel the label, wrap broken glass in newspaper...) in `note`. Use "any" (leave the condition out of `when`) wherever a condition does not matter for that item, so the app asks as little as possible. The case the sources are silent on (a plastic container with food it will not lose by rinsing) goes to "ask your district office", citing the README note. If a combination is not covered by any quoted row, do not invent a rule: list it in the design as an open question and route it to "ask your district office" only if I agree; for now, design it that way and flag each such combination. Copy: friendly, plain English, tiles, says "South Korea, as published by Seoul in 2025", names both sources with dates and links, and says the rules vary by district.
2. **apps/which-licence/** from choosealicense data only: conditions `copyleft` (none / changed files only / the library only / the whole program), `network` (should running it as a network service count as distributing: yes/no), `patent` (do you want an explicit patent grant from contributors: yes/no), `credit` (must copies keep your copyright notice: yes/no). Outcomes: MIT, Apache-2.0, Unlicense, MPL-2.0, LGPL-3.0, GPL-3.0, AGPL-3.0, each with its choosealicense description. Rules cite the .yml file and the permission or condition key that decides it (for example `mit.yml: no patent-use`). Where no licence of the seven fits an answer set (for example no copyleft, patent grant wanted, no notice required), the rule says which nearest licence is offered and why in `note`, citing the yml facts. Copy: precise, list style, a short "not legal advice" line, attribution "Licence data from choosealicense.com, CC BY 3.0" with links.
